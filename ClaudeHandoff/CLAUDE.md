# Bouncer / «It's our FIELD» — инструкции для Claude

Unity 6000.3 (URP) + Blender 5.1 проект: аркадный 3D roguelite про дворовые вышибалы 90-х, онлайн-кооп до 4 (готов), PvP (впереди). Автор — соло-разработчик (Neon Yurt), общается по-русски.

Полная память о проекте (этап разработки, решения, архитектура, пайплайны): @ClaudeHandoff/PROJECT_MEMORY.md
Детали по темам лежат в `ClaudeHandoff/memory_full/` — перед задачей по теме открой нужную заметку (карта в конце PROJECT_MEMORY.md).

## Обязательные правила
- Никогда не делай `git commit` / `git push` — автор коммитит сам.
- Не запускай Play Mode для тестов, автор плейтестит сам (исключение: запись трейлера через `Assets/_Trailer`). Проверяй компиляцию и консоль, правь сцены/префабы в Edit Mode. Перед Refresh/правкой скриптов проверь, что Unity не в Play Mode.
- После работы всегда пиши итог: что сделано и как проверить.
- Дизайн-проблема → сначала варианты (с рекомендацией ★), код только после выбора автора. Много замечаний сразу → нумерованный список вопросов.
- Надписи на 3D-моделях — только декаль-текстурой, не геометрией из шрифта.
- VFX мультяшные, без PS1-стилизации; без шейка камеры и хит-стопа на рутинных событиях. Фонарика у игрока нет (есть умение «Смена»), умения на Q/LB. Ёжик-мяч не трогать.
- Ассеты: правки в `Bouncer.blend`, экспорт `ba_export.export_named([...])` (не `export_all()`), без Apply Transform. Контентные блендеры — сохранять, по серии, ассеты линком.
- Новые строки интерфейса — в таблицу локализации `UI`/`Content` (ru/en, kk через CSV).
