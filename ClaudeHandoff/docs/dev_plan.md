# «Вышибалы» (Bouncer): план разработки + настройка репозитория

## Context
Концепт-документ `Vyshibaly_Concept.docx` описывает аркадный 3D roguelite про дворовые вышибалы (Unity, URP, PC/Steam, соло-разработка, PvE до 4 в коопе + PvP). Репозиторий `Bouncer` (origin `git@github.com:begod24/Bouncer.git`) пока пустой — только `README.md`. Unity-проекта ещё нет. Установлены Unity **6000.3.24f1** и Git LFS 3.6.1.
Цель: (1) разбить концепт на выполнимый поэтапный план; (2) подготовить `.gitignore` и `.gitattributes` **до** первого коммита Unity-проекта, чтобы бинарники сразу шли в LFS и не пришлось переписывать историю.

---

## Часть 1. Настройка репозитория (делаем первым)

### Структура
Unity-проект кладём **в корень репозитория** (`Bouncer/Assets`, `Bouncer/Packages`, `Bouncer/ProjectSettings`). Исходники арта (.blend, .psd, .kra) — в `Bouncer/ArtSource/` вне `Assets`, чтобы Unity их не импортировал; они тоже через LFS.

### Порядок действий
1. `git lfs install` (один раз на машине).
2. Создать `.gitignore` и `.gitattributes` (ниже), закоммитить.
3. Создать проект через Unity Hub (6000.3.24f1, шаблон **Universal 3D**) прямо в папке `Bouncer`.
4. Проверить в Unity: *Project Settings → Editor*: **Version Control = Visible Meta Files**, **Asset Serialization = Force Text** (по умолчанию так и есть).
5. `git add .` → проверить `git lfs status` / `git lfs ls-files`, что .png/.fbx попали в LFS → коммит → push.

## Часть 2. Архитектура проекта Unity

```
Assets/_Project/
  Scripts/  Core/ Player/ Ball/ Enemies/ Upgrades/ Waves/ Arena/ Net/ UI/ Meta/
  Data/     (ScriptableObjects: Balls, Upgrades, Enemies, Waves, Characters, TimeOfDay)
  Art/      Models/ Materials/ Palettes/ Shaders/ VFX/
  Prefabs/  Scenes/  Audio/  Settings/ (URP assets, Volume profiles, Input Actions)
```
- Пакеты: URP, Cinemachine 3, Input System, Netcode for GameObjects, Multiplayer Services (Relay/Lobby), TextMeshPro/UI Toolkit, Addressables (позже), Steamworks.NET (к этапу Steam).
- Asmdef на каждую папку Scripts — быстрая компиляция и чистые зависимости.
- Данные — ScriptableObjects (`BallDefinition`, `UpgradeCard`, `EnemyDefinition`, `WaveDefinition`, `CharacterDefinition`, `TimeOfDayProfile`).
- Пулинг: `UnityEngine.Pool.ObjectPool<T>` для мячей и врагов.
- Сразу писать геймплей «сетево-готовым»: логика мяча/попаданий отделена от визуала, состояние в явных компонентах — чтобы на этапе 3 не переписывать.

## Часть 3. План разработки по этапам

### Этап 0 — Подготовка (1 нед.)
- Репозиторий, LFS, `.gitignore`/`.gitattributes`, проект Unity 6.3 URP.
- Структура папок, asmdef, Input Actions (клавиатура+мышь и геймпад).
- Серая тестовая арена, Cinemachine-камера 3/4 (~55°).

### Этап 1 — Прототип (4–6 нед.) — «весело ли кидать мяч?»
1. Контроллер игрока: бег, рывок-уклонение с кулдауном.
2. Мяч: бросок (обычный + заряд удержанием), рикошеты от стен/врагов, мяч как ресурс, подбор.
3. Прицел: автоприцел / ручной, переключатель в настройках.
4. Ловля: кнопка + окно тайминга; ловля вражеского мяча = +мяч и +жизнь; «свечка» (ловля после высокого отскока → усиленный бросок).
5. Один враг (Неваляшка): NavMesh + анимация → ragdoll при попадании → встаёт.
6. HP игрока, смерть, рестарт. Debug-меню для тюнинга параметров.
- **Критерий выхода:** 5 минут в серой арене приносят удовольствие; параметры вынесены в SO.

### Этап 2 — Вертикальный срез (2–3 мес.) — сделан в сентябре 2026
1. **Визуал:** flat-shaded low-poly, палитры через материалы/градиенты; URP Renderer Feature для пикселизации + дизеринга, туман; цветокоррекция по времени суток (`TimeOfDayProfile` + Volume blending).
2. **Арена «Двор»** в финальном стиле: песочница (замедление), качели (отбивают мяч).
3. **Враги (3):** Неваляшка, Пупсы (рой — простой steering, без NavMesh на каждого), Оловянный солдатик (стреляет ловимыми мячами).
4. **Система волн** на SO, лимит 20–40 врагов, пулинг.
5. **Апгрейды — 10 карточек-вкладышей:** опыт/уровень → выбор 1 из 3. Система модификаторов мяча (стек эффектов: тип мяча + модификаторы + пассивки).
6. **Босс:** Большая неваляшка (делится при попадании).
7. UI: карточки-вкладыши, HUD мелом, меню. Базовый звук.
8. Профилирование: 60 FPS при 40 врагах + ragdoll.
- **Критерий выхода:** законченный 5–7-минутный кусок забега, можно показывать людям.

### Этап 2.5 — Полный соло-забег (решено 24.09.2026, до сети)
Решения второго опроса записаны в концепт-документе. Плейтест после А+Б, дальше после каждого этапа.
- **А. Забег без опыта (на Дворе):** состояние забега между сценами (карточки, сердца, монетки, арена); опыт и уровни убраны; редкость карточек (обычная / редкая / золотая); монетки 1 тиын / 5 тиын / 1 тенге с магнитом, в конце арены слетаются; стартовая карточка 1 из 3 обычных; портфель (элитки + один найденный за арену, 1 из 3 любой редкости); карточка за босса (1 из 3 редких/золотых); ларёк «Союзпечать» на краю каждой арены — витрина из 4 жвачек с видимыми вкладышами, перебор за монетки, замок, лимонад +1 сердце, бутерброд — все сердца; стрелка мелом на следующую арену; итоги забега; оставшиеся карточки (Стеночка, Рогатка, Глаз-алмаз, Домино, Копилка под монетки, «Портфель» переименовать) и комбо Йо-йо.
- **Б. Игрушки двора:** мишка (мяч застревает, выбивается другим мячом), цыплёнок (таран по прямой, взрыв задевает всех), юла (бильярд), лошадка-качалка (раскачка → таран); 7 элиток по расписанию 1–2 за арену, ×3 жизни и своё умение, роняют портфель + 5 тиын.
- **В. Хоккейная коробка (вечер) — сделано и проверено 25.09.2026:** сцена Rink (борта 40×26 с «идеальным» рикошетом — `RicochetSurface`: без потери скорости и высоты, не тратит лимит, доводка на врага; прожекторы загораются к вечеру; NavMesh, 16 точек спавна, скамейки и калитки как `ArenaSpot`), волна Wave_Rink (игрушки + первые манекены, 2 элитки, босс на 270 с); манекен (замирает под взглядом ~70°, новая поза на каждой остановке); босс Физрук-манекен: ходит всегда, планшет вблизи, сильные мячи издалека, свисток каждые ~12 с — «Замри!», «Штрафной!», «Мяч в игре!» (огромный мяч), «Замена!» (подмога со скамейки).
- **Г. Стройка (сумерки) — сделано и проверено 25.09.2026:** сцена Site (темнота: профили SiteDusk/SiteNight, свет только у фонарей, прожекторов, бочек с огнём, окна бытовки — `LightZone`/`LampLight`; круг света вокруг игрока — `PlayerLantern`); чучело (ловит мячи спереди, бросает обратно), тень (твёрдая на свету и на замахе) + дым; элитки сумерек (манекен из универмага — мяч в спину, чучело в ушанке — ловит и заряженные, тень в шляпе — гасит фонари); в конце пачка из трёх элиток, без босса. Пока стройка — последняя арена прогулки: её победа заканчивает забег.
- **Вместе с В и Г (25.09.2026):** 13 новых карточек (колода 37: обычных 12, редких 13, золотых 7, комбо 5) и погода как случайное событие арены (~30%: дождь с лужами, гроза с молниями, туман вокруг игрока).
- **Д. Финал «Мама зовёт домой» — сделано и проверено 25.09.2026:** наш двор лунной ночью (TimeOfDay_YardNight), 3 минуты, на арене только «Тот, кто в сумерках» и те, кого он зовёт сам. Часы до зова — окна панелек загораются одно за другим (накладки `WindowClock`), в HUD панелька мелом с окнами и отсчёт; последним загорается наше окно с мамой. Зов (время вышло или босс выбит) — дверь подъезда светится, в проходе между гаражами стрелка «Домой!»; добежал — персонаж сам бежит к двери, прогулка пройдена; выбили по дороге — проигрыш (`HomeCall`). Босс — Бабай с мешком и клюкой (`DuskBoss`, 120 попаданий, 3 фазы по жизням или по времени): «Ловец» (ловит мячи спереди и отвечает веером сильных), клюка вблизи и сильный мяч издалека; умения — «Прыжок на шесте», «Мешок» (собирает мячи, попадание в мешок сзади их высыпает), «Вороньё» (`CrowEnemy`: пике по прямой с полосой на асфальте, крадут мячи в мешок), «Карусель» (спираль ловимых мячей), «Считалочка» (спрятаться за ракетой, ларьком или качелями, `CoverVolume`), «Гасит свет» (`LightsOut`: темно 9 с, выходят тени), «Прятки» (ложные чучела `ScarecrowDecoy`, настоящего выдают глаза). После зова — прыжки на игрока, в свет подъезда не заходит (`LightZone.repelsDusk`). Прогулка: Двор → Коробка → Стройка → Финал.

### Этап 2.6 — Дети вместо капсулы (25.09.2026, ждёт плейтеста)
Решения 25.09: дети отличаются только внешностью (статы и коллайдер одинаковые, сборку делают карточки); имена Отличник, Толстяк, Мелкая, Хулиган; все одного роста; Мелкая в шортах, ранец только у Отличника; анимации свои из Blender; выбор перед прогулкой, все открыты.

### Этап 2.7 — После релиза на itch.io: патч, баланс, контент (27.09.2026, ждёт плейтеста)
Отзывы с itch.io и замечания автора разобраны в двух опросах 27.09, решения записаны в концепт-документе. Порядок: патч → баланс → контент; сеть — после соло.
- **Патч (сделано):**
  - подбор: сам в радиусе 1,5 м, ПКМ притягивает лежащий мяч до 2,5 м, если рядом нечего ловить;
  - застрявший мяч сам выкатывается к проходимому месту; враг за картой возвращается внутрь;
  - на арене остаются только мячи игрока, чужие исчезают через 1 с после приземления (28.09 заменено: до 7 чужих мячей лежат на арене, см. ниже);
  - попадания «столбиком» по высоте мяча: пупсы, цыплята и мини-юлы больше не пропускают мяч над головой;
  - стройка — полутьма; наводящий фонарик на Q / LB — базовое умение на тёмных аренах (заряд 3 с, жжёт тени), карточка «Фонарик» его усиливает;
  - HUD крупнее на подложке, кольца перезарядки у ног (рывок, ловля, лечение, крышка, фонарик), мигает последнее сердце;
  - неваляшки в фиолетовом платке в горошек (Bouncer → Art → Rebuild Roly-Poly Kerchief);
  - описания карточек с цифрами и «1/3»;
  - казахский язык: локаль kk, шрифт Caveat, таблица для перевода `Tools/Localization/kk_translation.csv` (Bouncer → Localization → Export / Import Kazakh CSV);
  - таймер прогулки и локальные рекорды (экран «Рекорды»).
- **Баланс (сделано):**
  - 6 карманов: стопки одной карточки — 1 карман, комбо — 1 карман на две; тип мяча и денежные карточки карман не занимают. Полные карманы — выкинуть (карточка вернётся в колоду) или продать в ларьке за полцены;
  - за прогулку 1 золотая и не больше 2 комбо;
  - цены 25/50/90, +20% за арену, +10% за каждую покупку в том же ларьке; перебор 5 (+5); лимонад 15, бутерброд 40;
  - монетки с обычных врагов с шансом 35%, портфель только с одной из двух элиток, находка на арене — монетки или лимонад;
  - нерфы: двойникам без «Хулиганства» и наведения, «Ещё мяч» и «Скакалка» до 2 раз, рывок не чаще 0,6 с, «Цепкие руки» не расширяют идеальное окно;
  - враги крепче по аренам (×1,5 в коробке, ×2 на стройке для врагов от 2 попаданий);
