Bouncer 3D assets are built in ONE Blender file outside the repo: `/Users/bekbolataldiyarov/Desktop/projects/Bouncer.blend` (user's choice, 2026-09-23). Generator scripts are embedded as text blocks (`ba_lib.py`, `ba_enemies.py`, `ba_balls.py`, `ba_yard.py`, `ba_export.py`, `build_all.py`, `README_assets.txt`). `ba_export.export_all()` writes FBX to `Assets/_Project/Art/Models/{Enemies,Balls,Yard}` and palettes PNG to `Art/Palettes`.

Coloring: single material `M_Palette` (shader `Bouncer/PaletteLit`) + 64x64 palette (8x8 cells). Time of day swaps palettes globally via `TimeOfDayController` (Scripts/Visuals). Tint/flash go through `_TintColor`/`_FlashColor` (see `Core/PaletteShader.cs`), not `_BaseColor`.

Export quirks (learned the hard way, 2026-09-23):
- Blender's "Apply Transform" (bake_space_transform) breaks nested hierarchies (limbs under a body get 90° rotations). Export uses native axes (forward Y, up Z) + Unity `bakeAxisConversion` (set in `Scripts/Editor/ArtImportPostprocessor.cs`), and temporarily turns assets 180° around Z so fronts (-Y in Blender) face +Z. Net mapping Blender (x,y,z) → Unity (-x, z, -y).
- The user's Blender GUI may have another project open; don't switch it — run `/Applications/Blender.app/Contents/MacOS/Blender -b Bouncer.blend --python script.py` instead (a harmless `bgl` add-on error prints on startup).
- NavMeshAssetManager bake deletes the previously referenced NavMesh asset; a copied scene shares it with the source scene, so restore/check the source scene's NavMesh after baking a copy.

Branding art (2026-09-24): Bouncer.blend has scenes `Splash` and `Icon` built by text blocks `ba_branding.py` / `build_branding.py` (linked duplicates of the assets, prefix SPL_, icon objects suffix _Icon, material SPL_Palette with distance haze; the export ignores them). Rerun build_branding.py after build_all.py. Cycles renders: Splash 3840x2160, Icon 2048x2048 transparent. `Tools/branding_art.py splash|icon <render>` writes Splash_Background/EN/RU, Splash_Logo_EN/RU and App_Icon.png (macOS grid: 824 px superellipse tile in 1024, shadow) into `Art/UI/Branding` (sprites via ArtImportPostprocessor). Player Settings: splash = Splash_EN (no Unity logo, overlay 0, one empty 3 s logo slot), Default Icon = App_Icon. Scripting gotcha: in `blender -b`, matrix_world of objects in a non-active scene is not evaluated by view_layer.update(); compose parent chains from matrix_basis instead. The GUI Blender can switch to another (unsaved) project mid-session: check bpy.data.filepath before running code in the live instance. Unity `AssetDatabase.SaveAssets()` also flushes dirty TMP dynamic font atlases (noisy diffs in Art/Fonts).

Stage-1 and advance assets (2026-09-24): new text blocks `ba_pickups` (coins, briefcase), `ba_shop` (kiosk, gum, lemonade, sandwich), `ba_toys` (bear, chick, top, rocking horse; builders take an `extras(parts)` hook), `ba_elites` (Elite_* built from the base builders + `recolor()` UV cell remap + `merge_into()`; `adopt_names()` fixes the fixed part names of ba_enemies copies), `ba_dusk` (mannequin, scarecrow, shadow; `scale` param), `ba_bosses` (Boss_Fizruk = mannequin x2.2, Boss_Dusk = scarecrow x3.0), `ba_rink`, `ba_site`. Collections Pickups/Shop/Rink/Site export to `Art/Models/{Pickups,Shop,Rink,Site}`. `ba_lib` also builds T_Palette_Evening/Dusk/Night (Unity profiles TimeOfDay_Evening/Dusk/Night created too). Use `ba_export.export_named([...])` — the FBX header has a creation time, so `export_all()` dirties every model in git. Text is never geometry: see [[inscriptions-as-textures]] (M_Decals, `Bouncer/PaletteDecal`, `Tools/decal_art.py`). Unity-rendered item icons (`Icon_Item_*`, `Icon_Portfel`) follow the ball-icon recipe in [[card-icons-pipeline]]. Working method: edit copies of the text blocks in the scratchpad, push them with `text.from_string()` + `as_module()`; when the user opens Bouncer.blend in the GUI Blender, work there through the MCP (check `bpy.data.filepath` every call); when the GUI Blender is closed, use `blender -b` and save. The GUI once quit mid-session, and the file kept the last GUI save.

Rigged assets (kids, 2026-09-25): `ba_kids.export_rig()` turns mesh data AND armature bones (`Armature.transform(TURN)`) for the 180° export, FBX with armature options (no leaf bones, deform only, `bake_anim_use_all_actions` only for Anim_Kids, scene fps set to 30 during export). Pose keys are local to bones, so they survive the turn. Blender 5.x actions are slotted: read fcurves through `layers[].strips[].channelbags[]` when `action.fcurves` is missing. See [[kids-concept-sheet]].

Roly-poly kerchief (2026-09-27, Unity-side because a parallel session held Bouncer.blend): the red head read as a ball, so `Scripts/Editor/RolyPolyKerchief.cs` (menu Bouncer → Art → Rebuild Roly-Poly Kerchief) copies RolyPoly_Head / BigRolyPoly_Head from the FBX with palette cell 1,7 red → 0,3 purple (boss cracks 5,7 → 7,4), builds a knot + tails + back corner mesh, saves them in `Art/Models/Enemies/Kerchief/` and dresses RolyPoly, RolyPolyDebris and Boss_RolyPoly_Big/Medium/Small (child `Kerchief`, ×3 on the boss). After re-exporting those FBX from Blender, rerun the menu; or move the kerchief into ba_enemies one day. Purple was picked because balls already use red, blue (volleyball), yellow-green, coral and brown cells.

Stage-3 assets (2026-09-27): text blocks `ba_toys2` (8 enemies), `ba_bosses2` (Transformer, Hare, battery), `ba_bazaar`, `ba_kindergarten`; collections Bazaar/Kindergarten export to `Art/Models/{Bazaar,Kindergarten}`. Two-pose model: the Transformer's parts are built in car coordinates, the car pose is stored in root["car_pose"]; `ba_bosses2.export_transformer()` writes Boss_Transformer.fbx (robot) + Boss_Transformer_Car.fbx (same hierarchy and names, node rotations conjugated by T = diag(-1,-1,1) for the 180° export turn; Unity's bakeAxisConversion keeps them right), and `TransformerRig` captures the car pose by part name. The decal atlas `T_Decals` must stay 2048×2048: an entry that doesn't fit grows it to 4096 and shifts every old UV — append small entries at the END of Tools/decal_art.py and compare old pixels.
