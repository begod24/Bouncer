Decisions by the user:
- Player stayed a capsule until 2026-09-25; then the user asked for the four kids (see [[kids-concept-sheet]]).
- The user calls the roly-poly enemies (неваляшки) «матрёшки».
- Sounds: I synthesize them (`Tools/sfx.py`); music the user brings themselves (mp3 in `Audio/Music`). For the new cards the user said «звуки не надо»: no new SoundCues/WAVs, effects reuse existing cues (BallWall, AreaThud). The user also drops their own SFX into `Audio/SFX` (e.g. SFX_GameCountdown.mp3) — leave those alone.
- Settings → Игра → «Подсказки» (2026-09-25, `GameSettings.ShowHints`, default on): hides the HUD controls help (H toggles the same setting and saves it) and the control lines at the bottom of menus/pause/shop/cards/kid select (`UI/HintText` on each `Hint`). By the user's choice it does NOT hide rule explanations under the rule banner or the arena hints under the arena title; the kiosk prompt stays too.
- Master volume is a multiplier inside SoundPlayer/MusicPlayer (`GameSettings.*Gain`), not AudioListener.volume and no AudioMixer.
- Fonts: Neucha + Caveat (Google Fonts, OFL) in `Art/Fonts` — both cover Latin and Cyrillic.
- Runtime UI: uGUI + TextMeshPro (chosen by me, user didn't object).
- Hit feel (2026-09-24, user said hit-stop + shake felt like freezes): no global `GameFeel.HitStop` on ordinary hits/kills or card effects. The enemy's own `Visual` reacts instead (`HitPunch`: squash, recoil, jitter), plus a white flash and a light shake. `Shake` merges shakes that arrive within 0.1 s. HitStop is kept only for rare moments (player hurt, catch, swings, boss split) and never plays twice in a row.

**Why:** keeps future sessions from re-asking settled questions.
